# RexETerm App

RexETerm 的图形界面版本，通过 Tauri command 调用进程内 Desktop 和共享 AppCore。
当前提供 Windows 原生工作区预览，与普通 MCP stdio 版共用后台模块和状态核心。

## 当前能力

左栏提供总览、Host、当前 RE 文件树和运维。总览显示此 App 的执行器、PTY、文件传输及运行中的转发列表；
Host 和文件树用于浏览具体节点，树下显示选中项目的属性。
中心在文件浏览、只读文件预览和任务 PTY 之间切换。
底栏提供任务、文件传输、端口转发三个列表。
任务仅显示当前 AppCore 创建并获得 asyncID 的 exbash 记录，传输与转发列表属于当前 App 客户端；它们不是系统全部进程或全局管理列表。

可以保存和连接 Host、按名称或正则内容搜索、运行/停止任务、接入 PTY 输入输出、
上传/下载/取消文件，以及创建和停止 TCP 转发。MCP HTTP 默认关闭，可在窗口中随时启停。
所有业务能力复用同一 AppCore，文件内容走 RE 数据通道。

当前使用单窗口、单个活动 PTY 预览。关闭预览释放通道并保留远端任务；正常退出取消文件任务，
关闭 PTY、运维连接、HTTP 和共享核心。主题/布局持久化、编辑器与安装包属于后续工作。


总览只显示活跃项；完成、取消、失败的文件任务及已退出的 PTY 从总览隐藏，底栏保留本实例的历史。

## Host 运维

运维入口按 Host 通过独立管理连接读取 rexed 全局快照，提供客户端、任务、PTY 通道、文件通道和转发通道五页。
客户端按 RE 用户分组，显示客户端标识、会话、IP、链路数量和全部链路合计入站/出站 MB/s。
无需先连接业务端；默认尝试业务网络端口 + 1，也可设置独立地址和管理员认证 profile。
服务端默认管理入口仍为本地 Unix socket，远程访问需由服务端显式配置可达管理监听。
权限不足或不可达时显示原因并清除旧快照，不影响业务任务。页面只读，不提供全局资源控制。
