# 工作区前端模块

## 范围

[app.js](../../frontend/app.js) 渲染 Tauri 中的单窗口工作区。
页面使用静态 HTML/CSS/ES modules，通过 desktop_call 读取实际状态。

## 子职责

左侧 rail 切换总览、Host、文件树和运维。总览读取 App 的所有已连接执行器、
打开的 PTY、正在传输的文件和运行中的转发，显示统计卡片及列表，并提供返回对应操作视图的入口。
Host 列表支持筛选、新增和连接；文件树展开时读取远端目录，
选中文件进入中心预览，选中文件夹更新目录。树下属性区显示 stat 的类型、大小、修改时间和路径。
文件夹不计算递归大小。

中心在文件浏览和预览标签间切换。文件浏览支持路径、面包屑、后退、上级、分页和两类搜索。
文件预览只读，远端文本使用 textContent 或 HTML 转义；二进制和大文件显示实际限制。
任务预览使用随包提供的 xterm，输出保持 ANSI/控制字节，输入直接发送到当前 PTY。
主控、只读、已退出和断连都有状态提示。关闭预览释放通道并保留任务。

底栏「任务」只列出当前客户端的 exbash 活动任务和 AppCore 保存的完成元数据，可打开 PTY、运行命令和停止任务；
「文件传输」显示此 App 的方向、实际字节、总量、平均 MB/s 和取消操作，完成后保留最终平均速度；
「端口转发」显示此客户端的 TCP 监听、远端目标及活动连接，可新增和停止。
列表使用当前 Host 筛选，每 1.8 秒刷新可见底栏。

MCP HTTP 开关显示后台实际地址与绑定错误，停止监听不关闭 RE。
侧栏与底栏可拖动调整大小，Ctrl+K 聚焦搜索，Alt+↑ 返回上级。

## 运维页面

[management-view.js](../../frontend/management-view.js) 渲染客户端、任务、PTY 通道、文件通道和转发通道五页。
运维 Host 选择独立于业务 Host；连接设置允许独立管理地址和管理员认证配置。
客户端按用户名分组，显示 clientId、sessionId、来源 IP、全部链路总速率与累计量。
速率使用服务端快照中的总量，按 RE 入站/出站方向展示，1 MB = 1,000,000 字节；不完整统计明确标注。
任务显示命令、目录、创建归属、创建时间及 PTY 主控会话，通道显示归属和标题描述。
所有远端内容做 HTML 转义；切换 Host 或失败清除快照，过期响应通过请求代次丢弃。
成功后定期刷新，失败停止自动重试；离开运维释放对应连接。

## 状态与边界

请求序号阻止过期浏览、预览和底栏结果覆盖新选择。
PTY 输出在 xterm 完成当前批次后再读取，输入串行发送；网络与任务由 Rust 后台持有。
PTY 使用独立二进制 terminal_poll 等待后端数据，无固定 60 ms 间隔；批量输出只等待该批的 xterm 写入完成。
[terminal-batch.js](../../frontend/terminal-batch.js) 验证批次版本、关闭标志、记录长度和类型，
将原始载荷的 Uint8Array 视图直接交给 xterm，不逐字节构造数字数组，也不再复制载荷。
仅元数据记录做 UTF-8 / JSON 解析，数据与元数据的顺序保持不变。
等待旧预览返回后先检查预览代次，再解码，避免切换后显示旧输出。
属性、布局、文件传输历史不持久化；窗口重载从后端读取现有工作区。
多终端标签仍为后续功能。


总览只显示活跃项；完成、取消、失败的文件任务及已退出的 PTY 从总览隐藏，底栏保留本实例的历史。
